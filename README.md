# 🎓 UniJobs

## 🚨 The Problem
University students struggle to find part-time jobs, tasks, or internships.  
Meanwhile companies have small tasks but no time to complete them.

## 💡 The Solution
UniJobs connects:
- Students looking for work or tasks  
- Companies needing help with tasks  

Both sides benefit.

## ⚙️ How It Works
### 👤 Student
1. Sign up & upload student ID  
2. Browse available tasks  
3. Apply & start working  

### 🧑‍💼 Company / HR
1. Register with company license  
2. Post tasks  
3. Review applicants  

## ⭐ Features
- Role-based login (Student / HR)  
- ID Upload (Student ID / Company License)  
- Tasks listing  
- Call center section  
- Profile & settings  
- Task posting system
