# 🎓 UniJobs
A mobile application designed to bridge the gap between university students and flexible employment opportunities through secure, schedule-aware matching.

## Project Idea
UniJobs addresses the critical challenge faced by Egyptian university students in finding safe, flexible work that accommodates their academic schedules. The platform connects verified students with trusted employers for part-time jobs, internships, and training opportunities using intelligent matching algorithms and modern UX/UI practices.


## Project Focus
🔒 Secure Verification System - Identity confirmation for both students and employers
🕒 Academic Schedule Integration - Smart job matching based on class timetables
🎯 AI-Powered Recommendations - Personalized opportunities based on skills and goals
📱 Modern Mobile-First Design - Intuitive interface designed for student usability
